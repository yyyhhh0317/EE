# 《失控因子》Unstable Factor

> 2D 动作肉鸽（Roguelite）· 俯视角 · 像素风 · 单机 · Godot 4 · GDScript

**一句话**：在情绪因子失控的世界里，玩家以"精准注射"对抗"过量注射"——把失控压在临界区刀尖跳舞，用六边形情绪共鸣构筑流派，一边爽快打怪，一边追寻失控实验背后的真相。

---

## 核心支柱

1. **情绪即力量**：8 种情绪因子（7 常规 + 1 混沌）既是怪物的变异之源，也是玩家的构筑核心。v0.2 已实装 4 种：怒 / 惧 / 喜 / 哀。
2. **控温博弈（双轨资源）**：理智（白条）与失控（红条）对冲——失控 70%~100% 为「亢奋临界区」（移速/攻速提升但无法冲刺、持续扣血），100% 触发「暴走」（伤害 +50% 但吞噬理智），理智归零 = 失控自毁。
3. **六边形情绪共鸣**：6 个环形槽位，相邻因子触发共鸣（怒+惧=战栗、喜+哀=释然），对立情绪共存产生第三属性，6 槽闭合解锁「情绪风暴」大招。
4. **乘法稀释与情绪污染**：同类因子堆叠收益递减 `(1+n)^-0.3`；只堆一种情绪会污染环境（怒→焦土灼烧 / 哀→浓雾 / 惧→幻影抖动 / 喜→敌人加速）。
5. **记忆碎片局外成长**：死亡/通关掉落碎片，可禁用不喜欢的因子（降方差）、预设开局共鸣。
6. **打怪为主、剧情为辅**：以爽快战斗为主体，用少量剧情碎片串联 8 个章节，逐步揭开真相。

## 如何打开工程

1. 用 **Godot 4.2+** 打开本目录（选择 `project.godot`）。
2. 首次打开会生成 `.godot/` 缓存，等待导入完成。
3. 运行（F5）：主菜单 →「开始游戏」进入**大厅** → 选第 1 章 / 商店（核心强化）/ 记忆碎片（禁因子、预设共鸣）→ 章节 → 通关/死亡 → Esc 返回大厅。

> 输入映射已内置于 `project.godot`：
> - **WASD/方向键** 移动 · **鼠标** 瞄准 · **左键** 发射 · **空格/Shift** 冲刺（耗理智）
> - **1-4** 注射因子（怒/惧/喜/哀，慢动作选槽）· **F** 情绪风暴（6 槽闭合）· **E** 交互 · **Esc** 暂停/返回

## v0.2 玩法速览

| 系统 | 一句话 |
| --- | --- |
| 理智（白条） | 冲刺 -15、大招 -60，+8/s 回复；暴走中被吞噬 18/s；归零 = 失控自毁 |
| 失控（红条） | 普攻 +1.2、受击 +8、注射 +10~15；自然衰减 6/s；70% 进亢奋、100% 暴走 |
| 亢奋临界区 | 移速 +15%、攻速 +20%，冲刺禁用、持续扣血 4/s —— 白嫖增益的代价 |
| 暴走 | 伤害 +50%、弹体 +30%、攻击不再涨失控，但理智被吞噬（回落 25/s 快于吞噬，满理智进入可存活） |
| 共鸣 | 怒+惧 相邻 = 战栗（命中恐惧敌人）；喜+哀 相邻 = 释然（失控衰减翻倍） |
| 对立制衡 | 怒×喜 = 躁动（亢奋阈值降至 60%）；惧×哀 = 麻木（受击失控 -50%） |
| 共振回路 | 6 槽闭合 → F 情绪风暴：全屏伤害，代价理智 -60 / 失控 +40 / 全体因子降 1 级 |
| 乘法稀释 | 词条数值 × `(1+同类槽数)^-0.3`，惩罚无脑堆同一情绪 |
| 情绪污染 | 单一情绪注射占比 ≥60% → 环境异变（焦土/浓雾/幻影/光污染） |
| 记忆碎片 | 死亡 5+阶段×2、通关 20+击杀×0.1；大厅禁因子（30/个）、预设共鸣（50） |
| 情绪过载 | 10s 内触发 ≥3 种共鸣/状态事件 → 1.5s 无敌 |
