# 《失控因子》Unstable Factor

> 2D 动作肉鸽（Roguelite）· 俯视角 · 像素风 · 单机 · Godot 4 · GDScript

**一句话**：在情绪因子失控的世界里，玩家以"精准注射"对抗"过量注射"——一边爽快打怪，一边追寻失控实验背后的真相。

---

## 核心支柱

1. **情绪即力量**：8 种情绪因子（7 常规 + 1 混沌）既是怪物的变异之源，也是玩家的构筑核心。
2. **风险与失控**：注射因子获得能力，但会累积"失控值"，过度注射将反噬自身——直接呼应"不合理注射导致怪物发狂"的主题。
3. **打怪为主、剧情为辅**：以爽快战斗为主体，用少量剧情碎片串联 8 个章节，逐步揭开真相。

## 如何打开工程

1. 用 **Godot 4.2+** 打开本目录（选择 `project.godot`）。
2. 首次打开会生成 `.godot/` 缓存，等待导入完成。
3. 运行（F5）：主菜单 →「开始游戏」进入**大厅** → 选第 1 章 / 商店（用核心买永久强化）→ 章节 → 通关/死亡 → Esc 返回大厅。

> 输入映射已内置于 `project.godot`（WASD/方向键移动、鼠标左键攻击、右键技能、空格/Shift 冲刺、Q 注射怒、R 注射惧、E 交互、Esc 暂停）。
