# 数据表设计文档——《失控因子》Unstable Factor

> 目标：让 8 章的大量内容（因子、怪物、技能、房间、事件、对话）都以**数据表**形式管理，策划/文案可批量编辑，代码只做通用逻辑。

---

## 1. 数据驱动原则

1. **代码写规则，数据写内容**：战斗、词条、AI、生成等通用逻辑写在代码里；具体数值、组合、文案写在数据表里。
2. **强类型定义 + 宽松内容**：
   - 表结构用 Godot 自定义 `Resource` 类定义（强类型、编辑器可视化、防拼写错误）。
   - 内容优先用 JSON/CSV 编写，由 `DataManager` 在启动时加载并转成 Resource（或直接读 JSON）。
3. **单一数据源**：所有系统只通过 `DataManager` 取数据，禁止硬编码数值/文案散落各处。
4. **可热更与可调试**：数据改动无需重编译，方便快速调平衡。

---

## 2. 资源格式选择

| 场景 | 格式 | 理由 |
| --- | --- | --- |
| 表结构定义 | Godot `Resource`（.gd 自定义类） | 强类型、字段校验、编辑器可读 |
| 内容编写 | JSON / CSV | 表格工具批量编辑、git 可 diff、跨工具 |
| 少量复杂引用 | `.tres` 资源 | 需要引用美术/场景等资产时 |

> 推荐工作流：**CSV/JSON 编辑 → DataManager 导入 → 运行时 Resource**。文本/数值类内容用 JSON，纯表格类内容用 CSV。

## 3. 数据表清单

| 表名 | ID 前缀 | 说明 |
| --- | --- | --- |
| 因子表 | `factor_*` | 8 种情绪因子定义 |
| 词条表 | `mod_*` | 所有 Buff/Debuff/被动词条 |
| 技能表 | `skill_*` | 主动技能 |
| 怪物表 | `enemy_*` | 敌人属性、AI 参数、技能、掉落 |
| Boss 表 | `boss_*` | Boss 专属（阶段、招式） |
| 房间表 | `room_*` | 房间模板（战斗/精英/事件/商店/休息） |
| 遭遇表 | `enc_*` | 战斗房内的怪物组合与波次 |
| 事件表 | `event_*` | 随机文字事件与选项 |
| 章节表 | `chapter_*` | 8 章配置 |
| 关卡表 | `level_*` | 每关的规则与随机池 |
| 道具表 | `item_*` | 消耗品（稳定剂、药剂等） |
| 掉落表 | `loot_*` | 掉落规则 |
| 对话表 | `dialog_*` | 剧情对话与选项 |
| 局外成长表 | `meta_*` | 永久强化、解锁 |
| 共鸣表 | `resonance_*` / `oppose_*` | v0.2：情绪共鸣（相邻）与对立制衡（共存） |
| 污染表 | `pollution_*` | v0.2：情绪污染（单一情绪占比 ≥60% 的环境异变） |

## 4. 各表字段定义

### 4.1 因子表（factor）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | 唯一 ID，如 `factor_joy` |
| `name` | String | 中文名（欢愉因子） |
| `emotion` | Enum | 喜/怒/哀/惧/厌/惊/忧/混沌 |
| `color` | Color | 主题色 |
| `keywords` | Array[String] | 主题词条标签 |
| `modifiers` | Array[ModRef] | 玩家注射获得的词条列表 |
| `skills` | Array[SkillRef] | 玩家注射获得的主动技能 |
| `instability_gain` | float | 每次注射增加的失控值 |
| `description` | String | 描述文案 |

### 4.2 词条表（modifier）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | 如 `mod_rage_stack` |
| `name` | String | 词条名 |
| `type` | Enum | 属性修饰 / 行为钩子 / 定时 / 层叠 |
| `stat` | String | 作用的属性（可选） |
| `operation` | Enum | 加/乘/百分比 |
| `value` | float | 数值 |
| `hooks` | Array[String] | 触发的行为钩子（on_hit/on_kill/on_tick…） |
| `duration` | float | 持续时间（0 = 永久） |
| `max_stacks` | int | 叠层上限 |
| `tags` | Array[String] | 标签（用于互动/免疫） |
| `is_negative` | bool | 是否负面词条（失控反噬用） |

### 4.3 技能表（skill）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | 如 `skill_rage_slam` |
| `name` | String | 技能名 |
| `emotion` | Enum | 归属因子 |
| `cooldown` | float | 冷却 |
| `cost` | String | 消耗（HP/SAN/失控值） |
| `behavior` | String | 行为脚本路径（逻辑实现） |
| `params` | Dictionary | 数值参数 |
| `visual` | String | 表现资源（动画/特效） |

### 4.4 怪物表（enemy）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | 如 `enemy_joy_splitter` |
| `name` | String | 怪物名 |
| `emotion` | Enum | 所属因子章节 |
| `hp / atk / def / speed` | float | 基础属性 |
| `ai` | String | AI 模板 ID |
| `skills` | Array[SkillRef] | 怪物技能 |
| `modifiers` | Array[ModRef] | 固有词条 |
| `loot_table` | LootRef | 掉落表 |
| `scene` | String | 场景资源路径 |
| `tier` | Enum | 杂兵/精英/小头目 |

### 4.5 遭遇表（encounter）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | 如 `enc_joy_01` |
| `emotion` | Enum | 所属章节 |
| `waves` | Array[Wave] | 波次（每波怪物组合+数量+刷新点） |
| `reward` | RewardRef | 通关奖励 |
| `difficulty` | float | 难度系数 |

### 4.6 房间表（room）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | 如 `room_combat_joy` |
| `type` | Enum | 战斗/精英/Boss/事件/商店/休息 |
| `emotion` | Enum | 所属章节（可空） |
| `encounter` | EncRef | 战斗房用（遭遇表） |
| `event` | EventRef | 事件房用（事件表） |
| `exits` | int | 出口数量（1~3） |

### 4.7 事件表（event）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | 如 `event_instability_01` |
| `title / text` | String | 事件标题/正文 |
| `options` | Array[Option] | 选项（文案+条件+后果） |
| `condition` | String | 触发条件 |
| `weight` | float | 随机权重 |

- `Option` 子结构：`text`（选项文案）、`effects`（后果：改资源/失控值/加词条/开战…）、`requires`（前置条件）。

### 4.8 章节表 / 关卡表（chapter / level）

**chapter**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | `chapter_1`…`chapter_8` |
| `emotion` | Enum | 对应因子 |
| `levels` | Array[LevelRef] | 关卡列表 |
| `enemy_pool` | Array[EnemyRef] | 怪物池 |
| `modifier_pool` | Array[ModRef] | 词条池 |
| `boss` | BossRef | 章末 Boss |
| `bgm / theme` | String | 音频/主题 |

**level**：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | `level_1_1`（章_关） |
| `room_count` | int | 房间数 |
| `room_pool` | Array[RoomRef] | 房间池 |
| `is_boss` | bool | 是否 Boss 关 |
| `seed_rule` | String | 生成规则 |

### 4.9 对话表（dialog）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | `dialog_ch1_open` |
| `speaker` | String | 说话人 |
| `lines` | Array[String] | 台词 |
| `choices` | Array[Option] | 分支选项（可空） |
| `next` | String | 下一节点 |
| `effects` | Array[Effect] | 对话后果 |

### 4.10 共鸣表（resonance，v0.2 新增）

六边形槽位上情绪因子之间的组合规则，代码只做「相邻检测/共存检测」，组合效果全在数据表。

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | `resonance_rage_fear`（相邻）或 `oppose_rage_joy`（对立） |
| `name` | String | 共鸣名（战栗 / 释然 / 躁动 / 麻木） |
| `emotion_a / emotion_b` | Enum | 参与的情绪对 |
| `type` | Enum | `adjacent`（相邻触发）/ `opposite`（同环共存触发） |
| `effect` | String | 效果标识（`fear_spread` / `calm_decay` / `threshold_down` / `damage_overheat_down`） |
| `params` | Dictionary | 效果参数（概率、持续时间、系数等） |
| `desc` | String | 描述文案 |

> 未来增加第 9、10 种情绪时，只需在共鸣表里加几行数据，不动核心代码。

### 4.11 污染表（pollution，v0.2 新增）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | String | `pollution_rage` |
| `emotion` | Enum | 触发污染的情绪 |
| `name` | String | 异变名（焦土地狱 / 浓雾 / 低语幻影 / 光污染） |
| `desc` | String | 描述文案 |
| `effect` | String | 效果标识（`scorch` / `fog` / `whisper` / `glare`） |

> 触发规则在代码里统一（单一情绪注射占比 ≥60% 且 ≥3 次），具体异变效果走数据表。

## 5. 数据表文件组织建议

```
res://data/
├── factors/
│   ├── factor_joy.json
│   ├── factor_rage.json
│   └── ...
├── modifiers/
├── skills/
├── enemies/
│   └── chapter1/           # 按章节归类
├── encounters/
├── rooms/
├── events/
├── chapters/
├── dialogs/
├── resonances/             # v0.2：共鸣/对立对照表
├── pollutions/             # v0.2：情绪污染表
└── meta/
```

> 建议按章节拆分怪物/遭遇/对话文件，避免单个文件过大、便于并行编辑。

---

## 6. 设计约束与校验

- **ID 唯一**：所有表用统一 ID 前缀，DataManager 启动时校验引用完整性（引用的 ID 必须存在）。
- **数值范围**：关键数值（如失控值增量、难度系数）建议在导入时做范围校验，防止手滑。
- **平衡调参**：所有战斗/经济数值都走数据表，调平衡不碰代码。

---

## 7. 首批要建立的数据表（最小集）

进入原型前，先建立以下 5 张表即可跑通核心循环：

1. **因子表**（先做 1~2 个因子）
2. **词条表**（5~10 个基础词条）
3. **技能表**（玩家基础技能 + 1 个因子技能）
4. **怪物表**（1~2 只基础怪）
5. **遭遇表 / 房间表**（1 个可玩战斗房）

其余表随内容量产逐步补齐。
