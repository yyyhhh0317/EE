# 游戏设计文档（GDD）——《失控因子》Unstable Factor

> 版本 v0.2 · 状态：关键决策已确认（视角/美术/武器/单机/命名），进入技术实现

---

## 1. 游戏概述

| 项目 | 内容 |
| --- | --- |
| 类型 | 2D 动作肉鸽（Roguelite） |
| 视角 | 俯视角（上帝视角，从天上看地图上的玩家） |
| 美术风格 | 像素风（剧情演出动画可更细腻） |
| 玩家武器 | 因子能量 · 发射型 |
| 平台 | PC 单机（手柄支持留待后期） |
| 引擎 | Godot 4 |
| 单局时长 | 单关 3~8 分钟，单局（一章）约 40~80 分钟 |
| 目标玩家 | 喜欢肉鸽构筑 + 动作战斗 + 心理/悬疑主题的玩家 |

**设计目标**：
- 以"情绪因子"为核心主题，所有系统都围绕它展开，避免"换皮肉鸽"。
- 战斗手感优先，构筑深度其次，剧情做"调味"不做"主菜"。
- 每章有鲜明的情绪体验差异（氛围、机制、怪物行为），而非仅换数值和皮肤。

---

## 2. 核心支柱（设计必须守住的三条）

1. **情绪即力量**：因子是玩家能力来源，也是怪物变异来源，同一个系统正反两面。
2. **风险与失控**：能力越强 → 失控值越高 → 反噬风险越大，形成肉鸽的经典"风险收益"决策。
3. **打怪为主，剧情为辅**：剧情用"碎片化、低干扰"方式穿插，绝不打断核心战斗节奏。

---

## 3. 世界观与剧情框架

### 3.1 背景设定

- 某科研机构研发出 **"情绪因子"**：一种可直接注射、用于调节/强化人类情绪状态的生物制剂。
- 初期被用于医疗与军事（抑制恐惧、激发斗志等），随后被滥用。
- **不合理注射**（过量、错误组合、未经适配的个体）导致受试者发生**变异发狂**，进而污染整片区域。
- 玩家是 **"零号受试者"**：体内天然具备**精准代谢因子**的能力，可以在控制剂量下注射因子并获得力量，而不至于立即失控。

### 3.2 玩家定位

- 身份：零号受试者（可自定义性别/外形，暂不影响剧情）。
- 目标：清理 8 个失控区域，逐步找回记忆碎片，查明"情绪因子计划"的真相。
- 手段：战斗中击杀变异体 → 回收因子精华 → 选择性注射 → 变强，同时维持失控值不崩溃。

### 3.3 剧情结构（少量、碎片化）

| 形式 | 说明 |
| --- | --- |
| 章节开场/收尾 | 每章 1~2 段短剧情（对话或演出），交代该因子的失控始末 |
| 房间事件 | 随机触发的文字事件，给世界观补充信息 + 提供肉鸽选择 |
| 记忆碎片 | 掉落道具，可在图鉴/档案中拼凑真相 |
| 结局 | 混沌章节（第 8 章）揭示真相，设 2~3 个结局分支（由玩家失控值与关键选择决定） |

> 原则：任何一段剧情单次阅读不超过 60 秒，可跳过；剧情永远服务于"给下一场战斗一个理由"。

## 4. 情绪因子系统（核心主题）

### 4.1 总览

- 共 **8 种因子**：7 种常规情绪 + 1 种混沌因子。
- 因子有**两种使用对象**：
  - **怪物**：被"过量注射"→ 变异发狂，获得该情绪主题的能力与行为。
  - **玩家**：被"精准注射"→ 获得对应词条/技能，但累积失控值。

### 4.2 七种常规情绪因子

| 序号 | 因子 | 情绪 | 主题色 | 环境氛围 | 怪物行为倾向 | 核心战斗词条 | 章节 Boss |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | 欢愉因子 | 喜 Joy | 明黄/亮粉 | 过饱和的游乐园/实验室，欢乐到诡异 | 亢奋高速、自我分裂、连锁增殖 | 加速、亢奋、分裂、连锁快感 | 狂欢之主 |
| 2 | 暴怒因子 | 怒 Rage | 暗红/橙 | 熔炉、崩塌工业区 | 越战越强、冲撞、无脑突进 | 激怒叠层、狂暴、震地 AOE | 狂暴巨人 |
| 3 | 哀恸因子 | 哀 Sorrow | 灰蓝 | 阴雨、迷雾的墓园/病房 | 减速、吸魂、徘徊 | 减速、沉默、生命吸取、悲伤结界 | 哀恸女妖 |
| 4 | 恐惧因子 | 惧 Fear | 深黑/暗紫 | 黑暗走廊，视野受限 | 潜行、背刺、惊扰 | 恐惧 Debuff、隐身、视野/光照机制 | 暗影吞噬者 |
| 5 | 厌恶因子 | 厌 Disgust | 绿紫 | 腐臭沼泽、下水道 | 传播、腐蚀、粘滞 | 中毒、腐蚀、粘液、瘟疫扩散 | 腐化聚合体 |
| 6 | 惊骇因子 | 惊 Surprise | 高对比白 | 闪烁镜像空间、错位房间 | 瞬移、突袭 | 瞬移、惊吓增伤、时空错位 | 镜影万相 |
| 7 | 忧虑因子 | 忧 Anxiety | 灰/浅紫 | 循环迷宫、压抑室内 | 缠绕、精神污染 | 焦虑叠层、反噬、心智值 | 心魔执念 |

### 4.3 混沌因子（第 8 种 · 特殊）

- 地位：**最终章**，也是所有失控的源头。
- 特性：**规则不稳定**——怪物能力随机、环境规则随机、玩家注射效果随机。
- 主题色：多彩失真/彩虹噪点。
- Boss：**实验体零号 / 混沌之源**。
- 机制：混合前述 7 种词条、随机刷词条、"规则突变"事件。

### 4.4 玩家侧的因子注射

玩家注射因子的规则（肉鸽构筑核心）：

- **因子精华**：击杀对应情绪的怪物掉落，可消耗注射。
- **注射效果**：获得该因子的词条（被动）或技能（主动），如"怒·狂暴"、"惧·隐身步"。
- **剂量与失控值**：
  - 每次注射都会累积**失控值（Instability）**。
  - 失控值越高，玩家获得的能力越强，但同时会随机获得**负面词条**（呼应"发狂"）。
  - 失控值突破阈值 → 触发**失控状态**：短暂混乱、视野扭曲、技能错乱等惩罚。
- **精准控制**：玩家可通过事件/道具"稳定剂"降低失控值，形成"强但要付出代价"的构筑抉择。

> 一句话总结：**怪物是"过量注射"的终点，玩家是"精准注射"的平衡者**，同一个系统正反呼应。

## 5. 玩家角色与能力

### 5.1 基础属性

| 属性 | 说明 |
| --- | --- |
| 生命 HP | 归零死亡（单局结束） |
| 心智 SAN | 忧虑/恐惧主题的额外资源，过低触发负面状态 |
| 移速 / 攻速 | 基础操作手感 |
| 攻击力 / 暴击 | 基础输出 |
| 护甲 / 抗性 | 减伤（分物理/情绪抗性） |
| 失控值 | 因子注射累积的风险条（见 §4.4） |

### 5.2 能力构成

- **武器**：以**因子能量**形式远程发射（发射型），主武器 + 副武器（局内可更换），因子会改变发射形态与弹幕效果。
- **技能**：主动技能若干（因子赋予 + 通用技能）。
- **词条**：被动修饰（因子词条 + 通用词条），肉鸽构筑的核心。
- **移动能力**：冲刺、翻滚（无敌帧），保证动作手感。

### 5.3 初始与局外

- 初始角色只有一个（零号受试者），局外可解锁不同**起始因子倾向/初始构筑**（meta 成长，见 §8）。

## 6. 战斗系统

### 6.1 战斗节奏

- 以动作躲避 + 技能释放为主，强调走位、无敌帧、怪物招式可读性。
- 怪物有明确的攻击前摇/预警（红圈、闪光、蓄力），避免"无法躲"的伤害。

### 6.2 伤害结算管线（设计约定）

```
攻击发起 → 命中判定 → 暴击/加成结算 → 抗性/护甲减免
        → 施加伤害 → 触发命中效果(吸血/毒/击退等) → 目标死亡判定 → 掉落/触发
```

- 所有加成以"词条（Modifier）"形式挂载，统一由战斗结算器按优先级执行（详见技术架构文档）。

### 6.3 状态效果（Buff / Debuff）

- 通用：中毒、减速、眩晕、击退、燃烧、吸血、护盾等。
- 情绪专属：亢奋、狂暴、恐惧、悲伤、腐蚀、惊吓、焦虑等（对应 §4.2）。

### 6.4 怪物设计原则

- 每章怪物基于"该章因子"的主题行为 + 通用基础怪（杂兵）。
- 精英怪：携带多词条/更强 AI。
- Boss：章节收尾，多阶段、可读招式的设计重点。

---

## 7. 关卡与章节结构

### 7.1 章节

- 8 章，分别对应 8 种因子；第 1 章为引导章（可放宽难度），第 8 章为终章（混沌）。
- 每章有独立的**视觉主题、环境音、怪物池、词条池、Boss**。

### 7.2 关卡（每章 8~10 关）

- 每关由**若干房间**通过**节点图**连接，玩家选择路径前进。
- 房间类型：

| 房间类型 | 说明 |
| --- | --- |
| 战斗房 | 常规打怪，通关给奖励 |
| 精英房 | 更难，给高质量奖励 |
| Boss 房 | 每章末关，章尾 Boss |
| 事件房 | 文字选择事件，影响失控值/资源/词条 |
| 商店房 | 用局内货币购买技能/词条/稳定剂 |
| 休息房 | 恢复 HP/SAN、降低失控值、整理构筑 |
| 起始/传送房 | 关与关之间的过渡 |

### 7.3 程序化生成

- 房间内容（怪物组合、奖励、事件）由**随机种子**生成；房间图拓扑随机但有规则约束（保证能通关、Boss 房在末尾）。
- 目标：每关"可重玩、每次不同"，但不追求无限开放世界（房间式地牢，非开放地图）。

---

## 8. Roguelike 循环

### 8.1 单局循环（Run）

```
进入章节 → 选择房间 → 战斗/事件 → 获得因子精华/货币/词条
        → 注射构筑 → 推进 → 章末 Boss → 通关进入下一章 或 死亡结算
```

### 8.2 局内构筑

- 词条组合、因子倾向、技能协同是构筑深度来源。
- 鼓励玩家在"单一情绪深耕"与"多情绪混搭"之间做取舍（混搭可能更强，但失控值更难控制）。

### 8.3 死亡与失败

- 死亡 = 本局结束，回到局外（Roguelite：保留部分 meta 进度）。
- 已解锁的局外成长、图鉴、剧情碎片保留。

### 8.4 局外成长（Meta Progression）

| 成长项 | 说明 |
| --- | --- |
| 起始构筑解锁 | 解锁不同初始武器/技能/因子倾向 |
| 永久强化 | 生命上限、初始资源、稳定剂容量等 |
| 图鉴/档案 | 怪物、因子、记忆碎片图鉴 |
| 难度层级 | 通关后开放更高难度/混沌污染等级 |

---

## 9. 剧情与演出（少量）

- 形式：短对话、过场镜头、环境叙事（场景中的日志/涂鸦）。
- 节奏：只在章节首尾 + 关键事件出现，单次阅读 ≤ 60 秒，全程可跳过。
- 目标：给战斗"意义感"，不喧宾夺主。

---

## 10. UI / UX 要点

- HUD：HP/SAN/失控值、当前因子词条、技能冷却、局内货币。
- 关键信息可视化：失控值用醒目的"风险条"表现，让风险收益一目了然。
- 词条面板：可随时查看当前构筑与负面词条。
- 暂停/设置：支持暂停、音量、手柄映射、画质等。

---

## 11. 美术与音频方向

- 美术：**像素风**（定案），统一"低饱和 + 每章情绪主题色点缀"的方向；剧情演出动画可更细腻，允许轻度逐帧/高清过渡。
- 音频：每章一个情绪主基调（BGM 情绪化），音效强调打击感与怪物预警。

## 12. 已确认决策（Key Decisions）

| 事项 | 决策 | 说明 |
| --- | --- | --- |
| 视角 | 俯视角（上帝视角） | 从天上看地图，玩家在平面上移动/瞄准；适合走位 + 发射型武器 |
| 美术风格 | 像素风 | 整体偏像素；剧情演出动画可更细腻 |
| 玩家武器 | 因子能量 · 发射型 | 以"因子能量"远程发射，因子改变发射形态与弹幕效果 |
| 多人/手柄 | 单机 | 首日不做多人；手柄支持留到 M7 |
| 正式名称 | 《失控因子》Unstable Factor | 取自"情绪因子 + 失控值"核心机制 |

### 12.1 视角与操作的直接影响

- 俯视角 + 发射型武器 → 战斗重心为**走位（移动/冲刺）+ 瞄准发射**。
- 默认键鼠：WASD/方向键移动、鼠标瞄准、左键发射、右键技能、空格冲刺。
- 地图以"上帝视角"呈现房间式地牢（房间内 TileMap + 节点图推进）。

### 12.2 命名备选（已择定主名）

- 《失控因子》Unstable Factor（**主名**）
- 《情绪因子》（原工作名，作为副标题/保留名）
- 《零号受试者》（呼应主角身份）
- 《情绪裂变》
