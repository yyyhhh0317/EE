## v0.2 · 玩法重构（已完成）

依据 idea/2.md（机制/数值/反馈诊断）与 idea/3.md（企业级机制与数值）落地，详见《05-玩法重构设计》。

- [x] 双轨资源：理智（白条）+ 失控（红条），状态机 稳定 → 亢奋(70%) → 暴走(100%) → 冷却
- [x] 六边形槽位构筑：6 槽环形 + 相邻检测 + 慢动作选槽注射 + 因子等级（≤Lv5）
- [x] 情绪共鸣：战栗（怒+惧）/ 释然（喜+哀）+ 对立制衡（躁动/麻木）+ 共振回路大招「情绪风暴」
- [x] 乘法稀释 `(1+n)^-0.3` + 动态难度（怪物伤害随玩家 DPS 权重自适应）+ 情绪污染（4 种环境异变）
- [x] 记忆碎片局外成长：禁因子（≤2 个）+ 预设开局共鸣
- [x] 反馈强化：注射白闪仪式、临界红光、暴走脉冲、情绪化暴击数字、情绪过载无敌帧、DPS 面板
- [x] 4 因子差异化：怒（狂战叠层）/ 惧（风筝减速）/ 喜（暴击经济）/ 哀（续航吸血）

**后续（M5 前）**：补齐共鸣对照表的其余情绪对、按章节主题化事件、平衡数值曲线（堆叠 10 层 < 搭配 5 层）。

## M0 · 工程骨架

**目标**：搭好可扩展的工程底座。

- [ ] 建立 Godot 4 工程与目录结构（见《02-技术架构》§3）
- [ ] 创建 8 个 Autoload 空壳并注册
- [ ] 打通 `GameManager` 顶层状态机 + `SceneManager` 场景切换
- [ ] 建立 `EventBus` 事件命名规范
- [ ] 建立 `DataManager` 与最小数据表加载
- [ ] 主菜单/设置占位场景

**验收**：能启动 → 主菜单 → 空场景 → 退出，无报错。

---

## M1 · 战斗原型（手感优先）

**目标**：做出一场"好玩"的最小战斗。

- [ ] 玩家移动、冲刺/翻滚（无敌帧）、普攻
- [ ] 1~2 只基础怪 + 简单 AI（索敌/追击/攻击前摇/死亡）
- [ ] `CombatResolver` 伤害结算管线（先无词条）
- [ ] 命中反馈：受击硬直、飘字、音效、屏幕反馈
- [ ] 一个可玩测试房（无限刷怪或单波）

**验收**：手感达标（移动/攻击/闪避连贯、伤害反馈清楚）。

> 手感是本项目成败关键，M1 不通过不进入 M2。

---

## M2 · 因子与失控（核心循环）

**目标**：把"情绪因子"主题变成可玩机制。

- [ ] `Modifier` 词条系统（属性修饰 + 行为钩子 + 层叠）
- [ ] 因子注射流程（击杀掉精华 → 注射 → 获得词条/技能）
- [ ] 失控值条 + 阈值触发负面词条/失控状态
- [ ] 稳定剂道具（降低失控值）
- [ ] 先实现 2 个因子（如"怒"和"惧"）验证差异化

**验收**：注射能明显改变战斗风格，且"高风险高收益"的失控决策成立。

---

## M3 · 第 1 章垂直切片

**目标**：完整跑通"一章"的所有环节。

- [ ] 房间类型齐全（战斗/精英/事件/商店/休息/Boss）
- [ ] 关卡节点图生成（8~10 关，末关 Boss）
- [ ] 章首/章尾短剧情 + 1 个事件房
- [ ] 第 1 章怪物池 + Boss（推荐先做"怒"或"惧"章）
- [ ] 局内货币 + 掉落 + 商店购买

**验收**：新玩家能无引导问题地通关第 1 章，体验完整。

---

## M4 · 肉鸽循环完整化

**目标**：把"单章"扩展成"可重复游玩的肉鸽"。

- [ ] 房间图随机 + 种子系统（可复现）
- [ ] 事件库（5~10 个通用事件）
- [ ] 死亡结算 + 局外成长（meta 永久强化）
- [ ] 存档系统（设置 + meta 进度 + 中断续玩）
- [ ] 难度/污染等级框架

**验收**：连续多局体验有差异、有成长、有重开动力。

---

## M5 · 内容量产（8 章）

**目标**：按已定 pipeline 横向铺满内容。

- [ ] 每章：怪物池（3~5 种）+ 精英 + Boss（共 8 Boss）
- [ ] 每章：词条池 + 技能 + 事件（情绪主题化）
- [ ] 每章：视觉主题 + 环境 + BGM
- [ ] 8 章关卡数据 + 平衡调参
- [ ] 混沌章节（第 8 章）特殊机制实现

**验收**：8 章全通，内容量足够，难度曲线合理。

> 量产阶段重点是把 M3 验证过的 pipeline 复用到 8 章，优先保证"每章情绪差异明显"。

---

## M6 · 剧情与演出

**目标**：补上"少量剧情"，给战斗意义感。

- [ ] 每章首尾剧情 + 关键事件
- [ ] 记忆碎片图鉴
- [ ] 混沌章节真相 + 2~3 个结局分支
- [ ] 对话/演出系统完善（可跳过）

**验收**：剧情不打断节奏、碎片可拼出完整真相。

---

## M7 · 打磨与发布

**目标**：达到可发布质量。

- [ ] 战斗/经济/难度全面平衡
- [ ] 音效、音乐、UI/UX 打磨
- [ ] 性能优化（对象池、同屏敌人上限）
- [ ] 手柄支持、键位、无障碍选项
- [ ] Bug 修复、多平台打包（Windows 优先）

**验收**：稳定 60fps、无明显 Bug、可打包分发。
