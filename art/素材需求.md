## 一、素材约定（重要）

| 项目 | 约定 |
|------|------|
| 格式 | PNG |
| 精灵图 | 透明背景（RGBA，PNG 色型 6） |
| 地图 | 可平铺地板，不透明 RGB 也可以（色型 2） |
| 尺寸基准 | 小怪 96×96、Boss 128×128、英雄 128×128、道具 96×96、地图 768×768 |
| 命名 | 小写英文 + 下划线，例如 `anger_mob1.png`、`essence_rage.png` |
| 摆放 | 角色/道具应尽量居中，四周留透明边，避免贴边被裁 |

## 五、如何替换 / 增补素材

1. 按上面的目录与命名放进 `art/`。
2. 回到 Godot 编辑器，等待自动导入（或点项目 → 重新导入）。
3. 若提示 `Art` / `Placeholder` 等类「未定义」，在编辑器里重新加载项目（或 Project → Reload Current Project）刷新脚本类缓存。
4. 想临时禁用某张图：把文件移出 `art/`，代码会自动回退到占位图，不会崩。

> 若之前出现过 `Not a PNG file` / `Error importing`，通常是旧图损坏或导入缓存过期：
> 用图片编辑器重新导出为 PNG，然后删除 `项目根/.godot/imported/` 让 Godot 重新导入。
