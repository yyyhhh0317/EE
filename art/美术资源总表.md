## 一、素材规范与加载方式

| 项目 | 约定 |
|------|------|
| 格式 | PNG，**必须是真 PNG**（见 §十，加载器直读字节） |
| 精灵图 | 透明背景（RGBA，PNG 色型 6） |
| 地图 | 可平铺地板，不透明 RGB 即可（色型 2） |
| 尺寸基准 | 小怪 96×96、Boss 128×128、英雄 128×128、道具 96×96、地图 768×768 |
| 命名 | 小写英文 + 下划线，例如 `anger_mob1.png`、`essence_rage.png` |
| 摆放 | 角色/道具尽量居中，四周留透明边，避免贴边被裁 |

**加载方式**：统一由 `res://util/art.gd`（`Art` 类）加载，用 `Image.load()` **直接读 PNG 原始文件、绕过导入管线**；
文件缺失或损坏时返回 `null`，调用方回退到 `util/placeholder.gd` 的程序生成占位图，**不会报错/崩溃**。

## 十、常见问题

- **`Not a PNG file` / `Error importing`**：`Art.tex()` 用 `Image.load()` **直读字节**，文件必须是真 PNG。
  典型的坑是「把 JPEG 直接改名成 `.png`」（扩展名对了、字节不对），必须用图片编辑器**重新导出为 PNG**。
  修好后删除 `项目根/.godot/imported/` 让 Godot 重新导入。
- **图片不显示但没报错**：说明文件缺失或损坏，`Art.tex()` 返回了 `null`，画面在用占位图——按上一条排查。
- **`.import` 文件丢失**：不影响运行（加载器绕过导入管线）；Godot 下次打开会自动重建。
- **命名不匹配**：见 §二 对照表；错名会导致回退占位图（例如曾出现的 `worry_*` 应为 `anxiety_*`）。
